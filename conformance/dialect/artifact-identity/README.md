# Named Dialect identity examples

Staged agreement fixtures for RFC 0021, not a released conformance corpus. These create **new**
documents and preparation commitments from existing public test inputs. The twelve historical
vectors are unchanged. `dialect.json` is the published document; `binding.json`, when present,
binds it to the fixture profile. `preparation.json` commits the bound document. The manifest pins
every file and both commitments. Do not infer publication authorization or source truth.
