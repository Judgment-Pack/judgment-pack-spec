## Review record (same vendor, not a cross-vendor claim)

One round, read-only, at 6237c83, by a reviewer that did not write the change. This is a same-vendor review. The maintainer waived the cross-vendor review for this line of work, so this record is the review for the Draft; it is not the RFC 0009 review, and accepting RFC 0032 remains a separate decision. Findings are closed in 7870843, which implements dispositioned findings only.

Found sound: Core `0.5.0` is byte-identical (text, schema, corpora, catalog, RFC 0031); every input Core refuses gets exactly one diagnostic, Core's; "last segment" is unambiguous under Core §5's identifier grammar; the row expectations agree with the companion text; the companion is in no bundle and has no site page; the wording names no organisation, product or industry.

Not checked: a built release bundle, the full site build; no second independent reader exists.

## Decisions

D1, D2, D4–D8, D12, D14, D15, D17, D19 (a), D20: accepted as written. D3 (`severity`, no prefix) and D10 (code spelling): accepted; the maintainer's call. D9, D11, D13, D16, D21: accepted with the changes below. D18: left for the selector that takes it up; (a) now carries the note that a new level then needs a new selector.
